# AI Football Predictor Pro 使用说明

## 🚀 快速启动

### 方法一：使用启动脚本（推荐）
1. 双击运行 `backend/start.bat`
2. 等待自动安装依赖并启动服务器
3. 浏览器自动打开 http://localhost:3000

### 方法二：手动启动
```bash
cd backend
npm install
npm run football
```

## 📖 使用指南

### 1. 预测比赛
- 在首页输入主队和客队名称
- 系统会自动搜索匹配的球队
- 点击"开始预测"按钮
- 等待AI深度分析完成

### 2. 查看预测结果
预测结果包括：
- **全场预测**：主胜/平局/客胜概率
- **半场预测**：上半场赛果预测
- **下半场预测**：下半场赛果预测
- **比分预测**：最可能的5个比分及概率
- **大小球**：大球/小球概率
- **双方进球**：都进球/至少一方不进球概率
- **战术分析**：双方战术风格对比
- **AI分析报告**：详细的比赛分析

### 3. 球队数据库
- 点击"数据库"标签
- 可以浏览所有球队
- 支持按地区筛选（欧洲、亚洲、美洲等）
- 支持搜索特定球队

## 🎯 功能特点

### 数据分析维度
1. **历史战绩**：双方历史交锋记录
2. **近期状态**：近5-10场比赛表现
3. **主客场**：主场/客场胜率对比
4. **伤停情况**：主力球员伤停影响
5. **战术风格**：进攻/防守/传控类型
6. **体能状况**：赛程密度分析
7. **战意分析**：争冠/保级压力
8. **市场数据**：赔率倾向

### AI智能分析
- 基于DeepSeek大语言模型
- 综合100+维度数据
- 生成专业分析报告
- 给出置信度评分

## 🔧 技术架构

- **前端**：HTML5 + CSS3 + JavaScript
- **后端**：Node.js + Express
- **AI服务**：DeepSeek API
- **图表**：Canvas API
